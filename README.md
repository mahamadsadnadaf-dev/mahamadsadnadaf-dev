## Projects

### 🧾 Papermen Billing — Automated Billing System for Paper Delivery Businesses
> Django · Celery · Redis · SendGrid · UPI QR Integration

End-to-end billing platform built to automate recurring invoicing for local paper delivery vendors. Uses Celery + Redis for scheduled billing cycles and background task processing, SendGrid for automated invoice/email delivery, and UPI QR code generation for direct payment collection. Designed to demonstrate real-world payment integration and task scheduling at a production-adjacent level.

---

### 📚 BookNook — AI-Powered Reading Tracker
> Python · Flask · SQLite · Google Gemini API · Open Library API · Tailwind CSS

Full-stack reading tracker built from scratch. Normalized SQL schema, RESTful CRUD endpoints, and multipart file handling for book cover uploads. Integrated the Google Gemini API with structured prompt engineering to auto-generate book metadata on demand. Served through Flask's production WSGI server.

---

### 🌐 Kalpvruksha — Online Education Platform
> HTML · CSS · Vanilla JS · PHP · MySQL

Full-stack education platform — no frameworks, no libraries. Custom routing, session handling, form validation, and assignment management built entirely in vanilla PHP. Responsive across desktop and mobile using semantic HTML and CSS only.
